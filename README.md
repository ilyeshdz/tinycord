# Tinycord

Tinycord is an open source, lightweight Discord client focused on keeping the desktop experience fast, clean, and comfortable.

It gives Discord a smaller native shell with room for thoughtful client-side improvements, custom plugins, and quality-of-life features without trying to turn the app into something heavy. The goal is simple: keep Discord feeling like Discord, but make it easier to shape, extend, and run.

Tinycord is for people who want a lean client they can inspect, modify, and build on. It is community-minded, hackable by design, and made for experiments that respect the feel of the original app while giving users more control over their experience.
